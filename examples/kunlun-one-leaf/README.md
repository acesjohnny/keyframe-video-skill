# One Leaf over Kunlun · 《昆仑一叶》 · 《崑崙一葉》

A 15-second, three-shot sample: the first end-to-end run of the keyframe video workflow in [`SKILL.md`](../../SKILL.md).

| File | What it is |
|---|---|
| `shots.json` | The three prompts exactly as submitted (Chinese prompts; the model, shot ids and lengths) |
| `keyframes/shot-01.png` … `shot-03.png` | The approved t = 0 images, one per shot — each clip starts from its keyframe |
| `kunlun-one-leaf.mp4` | The finished cut: 15.0 s, 1280×720, H.264 + AAC |
| `preview.gif` | A small preview for the README |

**Pipeline.** Storyboard approved → prompts approved → keyframes generated by an image model and reviewed → keyframes hosted on a temporary preview channel that expired after 24 hours → one `agnes-video-2.5-flash` task per shot (`mode: keyframe`, `720P`, `16:9`, 5 s) → clips normalized to one frame rate and pixel format, loudness-normalized, and concatenated with ffmpeg.

**What it does not show.** This run predates blocking, character cards, the prompt-language rules and failure classification; it has no dialogue. See the top-level README for those stages from a later 20-shot episode.

All media here are AI-generated; the keyframe PNGs carry the image generator's C2PA provenance manifest. The scene is inspired by the novel *Hua Qiangu* (《花千骨》) by Fresh果果; no text from the novel is used.
